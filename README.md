# דאשבורד שיווק דיגיטלי 📊

## שימוש
פתחו את **index.html** בדפדפן (לחיצה כפולה). אין צורך בשרת או התקנות.

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | הדאשבורד עצמו — עיצוב, גרפים, טבלאות, תובנות |
| `config.js` | **כאן עורכים פרמטרים**: כותרת, מטבע, צבעים, הפעלה/כיבוי ערוצים, טווח ברירת מחדל, יעד הוצאה יומי |
| `data.js` | שכבת הנתונים — נוצר אוטומטית, לא לערוך ידנית |
| `generate_demo_data.py` | מחולל נתוני דמו: `python generate_demo_data.py` |

## עריכת פרמטרים (config.js)
- כיבוי ערוץ: `enabled: false`
- שינוי צבע/שם ערוץ: `color` / `name`
- קו יעד הוצאה יומי בגרף: `dailySpendTarget: 500`
- כמות פוסטים בטבלה: `topPostsCount`
